# Technology Stack: Chatwoot

## Core Technologies
- **Language:** Ruby, JavaScript/TypeScript
- **Backend Framework:** Ruby on Rails (~> 7.1)
- **Frontend Framework:** Vue.js (v3)
- **Styling:** Tailwind CSS

## Data Storage & Infrastructure
- **Primary Database:** PostgreSQL
- **Caching & Real-time:** Redis (for Sidekiq and ActionCable)
- **Background Jobs:** Sidekiq
- **File Storage:** S3-compatible storage for attachments

## Deployment & Environments
- **Containerization:** Docker & Docker Compose
- **Platforms:** Heroku, DigitalOcean, self-hosted Linux servers
- **CI/CD:** CircleCI (as inferred from project files)

## Development Tools
- **Package Managers:** npm, pnpm, yarn, bundle
- **Testing:** RSpec (Ruby), Vitest (JavaScript)
- **Linting:** RuboCop, ESLint, Prettier
- **Assets:** Vite (for frontend asset management)
